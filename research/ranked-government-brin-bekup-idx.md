# Ranked Winners — Government Programmes: BRIN / BEKUP / IDX

Research date: 2026-11-15. Deep-research follow-up to
`research/winners-government.md` sections 7–9. Read that file first for the
baseline; this file records **rank explicitly per cycle** and only what this
round added or re-confirmed.

## How to read this file

- **Rank type** is stated for every cycle. Values used:
  - `ranked 1st/2nd/3rd` — the programme published an ordered Top 3.
  - `category winners` — awards by named category (winner per category, no
    overall 1st/2nd/3rd).
  - `sole winner` — one winner only (e.g. Best PPBR, one RIIM Startup Award).
  - `cohort / no-rank` — the programme publishes a selected/funded cohort and
    **no ranking by design**; cohort members are NOT winners.
  - `Top N, unranked` — a Top N list is published with no order.
  - `no-winner-published` — no winner/cohort list found in searchable text.
- **No rank was invented.** Where a source lists names without order, the
  table says so. Where only a 1st is published, 2nd/3rd are marked
  TBD/not published — not guessed.
- **Verification limit:** this round hit an upstream 429 rate-limit partway
  through (3 searches + 2 page opens failed). Items marked "429-blocked" were
  not searched/opened to completion, not proven absent.
