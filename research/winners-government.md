# Winners — Government Programmes (Indonesia)

Research date: 2026-11-15. Source file for programme definitions:
`cans/07-indonesia-programmes.md` (Government and state programmes).

## How to read this file

- **"Winner" means different things per programme.** Most of these are accelerators /
  incubators, not pitch competitions. Where no ranked winner exists, the published
  outcome is a **selected cohort / funded recipients / finalists** — labelled as such.
  Do not present cohort members as overall winners.
- **No winner was invented.** Every name below was verified via web search against a
  primary source (organiser site, press release) or reputable news. Unverifiable
  cycles are marked **TBD / Not found**, with what was searched.
- **Verification limit:** several searches in this round hit an upstream 429
  (Too Many Requests) rate-limit, cutting off some follow-up checks. "TBD" means
  *not found in the searches completed*, not proof no source exists.
- Cycle window: last 5 cycles actually held, dated 2022–2026 unless noted.
