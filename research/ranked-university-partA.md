# Ranked Winners — Part A: Innovative Academy (UGM) & SkyStar Ventures (UMN)

**Research date:** 15 November 2026
**Scope:** Deep re-research of the two university programmes in `research/winners-university.md` §§1–2 and `cans/07-indonesia-programmes.md` (University section), to (a) fill TBD gaps and (b) state the RANK explicitly for every cycle.
**Method:** `browser.search` (Indonesian + English) + `browser.open` attempts on primary sources (university/organiser sites, Instagram @ia.ugm / @skystarventures / @universitasmultimedianusantara, news, LinkedIn-adjacent press). Multiple sources checked per cycle; alternate spellings tried (Innovation Challenge, Demo Day, Startup Grant, Incubation Batch). No rank was invented.

## Rank-type vocabulary (used in every row below)

| Rank type | Meaning |
|---|---|
| `ranked 1st/2nd/3rd` | Source states an ordered 1st, 2nd, 3rd (or Juara 1/2/3) |
| `best-N unranked` | Source names N best teams with NO order between them — do NOT read as 1st/2nd/3rd |
| `category winners` | Source names a winner per category (e.g. Best Pitch, Public Choice) — no overall 1st/2nd/3rd |
| `cohort / no-rank` | Programme publishes a selected/funded cohort; no ranking exists by design |
| `no-rank (showcase)` | Event was a showcase / VC meet-and-connect, not a judged contest; no winner named |
| `no-winner-published` | Event happened, coverage exists, but no winner/ranking was published |
| `not yet held` | Cycle/event scheduled after the research date |
| `TBD-still` | Searched, not found; may exist in an unsearched source |

**Headline:** Across both programmes and all cycles 2021–2026, **no cycle publishes a ranked 1st/2nd/3rd**. The only winner-type outcomes ever published are: one `best-3 unranked` set (IA, June 2023) and one `category winners` set (SkyStar Batch 8, 2021). Everything else is cohort/no-rank or no-winner-published.

**Rate-limit caveat:** Mid-session the browser service returned HTTP 429 on one batch of 5 searches and on 2 `browser.open` attempts. All five blocked topics were subsequently covered by reworded single searches. No fact below rests on a page that was only snippet-read *except* where marked "snippet-only". The two blocked `browser.open` fetches (UGM 2025 Demo Day article; Digination Batch 8 article) were instead verified via search-result text from those same URLs.

## Part A1. Innovative Academy — Universitas Gadjah Mada (UGM)

**Structure (verified):** Three stages — (1) Pre-incubation, twice yearly as the **Innovation Challenge** (Feb/Mar and Aug/Sep intakes); (2) Incubation; (3) Acceleration. The PRIME STeP **Startup Grant** is a separate funding scheme run through Innovative Academy (up to Rp250m per startup, scheme cap, not a per-year prize). Source: https://ditpui.ugm.ac.id/program/innovative-academy/
**Numbering note:** IA uses overlapping numbering (Incubation Batch #11 Jul 2023, Batch #12 Mar 2024, Innovation Challenge Batch 14 Dec 2024, then "Innovation Challenge Batch 2025"). Cycles below are by year/Demo Day, plus a separate Startup Grant table, so no cycle is silently merged or double-counted. **Batch 13 gap:** no public source found for an "Innovation Challenge Batch 13" (numbering jumps Batch 12, Mar 2024 → Batch 14, Dec 2024); its existence/outcome is TBD-still — see "Still TBD".
