## How to read this file

- **Rank type is stated for every cycle.** `ranked 1st/2nd/3rd` = the
  programme published an ordered Top 3. `sole winner` = one winner only.
  `category winners` = awards by named category, no overall 1st/2nd/3rd.
  `cohort / no-rank` = the programme publishes a selected/funded cohort
  and no ranking by design; cohort members are NOT winners. `Top N,
  unranked` = a Top N list with no order. `no-winner-published` = the
  cycle ran but no winner list was found. `TBD-still` = searched, not found.
- **No rank was invented.** Where a source lists a Top 3/Top 5/Top 10
  with no order, it is recorded as unranked — never as 1st/2nd/3rd. Where
  only a 1st is published, 2nd/3rd are marked TBD/not published.
- **Verification limits:** all three trios hit upstream 429 rate-limits
  this round. Items marked SNIPPET-ONLY rest on search-result text
  (often corroborated by 2+ outlets) and need a live-browser re-check
  before being treated as fully verified. Items marked as Instagram-only
  need a live-browser check of the account's graphics. TBD means
  "not found in the searches completed", not proof no source exists.
